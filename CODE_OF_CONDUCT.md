# Code of Conduct

We want this project to be safe and welcoming for everyone.

Be respectful, patient, and constructive. Assume good intent, but take impact
seriously. Harassment, discrimination, personal attacks, and unwanted sexual
attention are not accepted.

Project maintainers may remove comments, contributions, or participants when
needed to protect the community. Report conduct problems privately through the
contact method in the repository security policy.

This code of conduct applies in project spaces and when representing the
project in public.
